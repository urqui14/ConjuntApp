Guía Rápida - ConjuntApp
1. Definición de Conjuntos

Ingresa los elementos separados por comas (ejemplo: 1, 2, 3 o a, b, c). El conjunto universal U establece el dominio para calcular los complementos.

2. Evaluador de Expresiones y Atajos

Puedes escribir fórmulas avanzadas usando los botones o directamente con el teclado de forma fluida:

N o n → Intersección (∩)
D o d → Diferencia Simétrica (Δ)
0 (Cero) → Elemento Vacío (Ø)
U o u → Unión / Universo
- (Guión/Menos) → Resta o Diferencia
' (Apóstrofo) → Complemento
Enter → Evaluar expresión de inmediato
3. Restricciones de Caracteres

Para garantizar la estabilidad del motor analítico, el sistema bloquea automáticamente caracteres o números extraños que no pertenezcan a la sintaxis de la teoría de conjuntos (solo acepta A, B, C, U y los operadores válidos).

4. Módulos Especiales

Conjunto Potencia (2ⁿ): Calcula al instante la cardinalidad y despliega todos los subconjuntos, incluyendo el conjunto vacío por defecto.
Producto Cartesiano: Permite seleccionar dinámicamente dos conjuntos para obtener los pares ordenados, su cardinalidad, el diagrama relacional y el plano cartesiano interactivo.
